# 🌐 Flask Activities

A collection of simple web applications developed with Python and Flask.

These activities were created during the Systems Development course at SENAI to practice Flask routes, HTML forms, data processing and the integration between Python and web pages.

## ✨ Activities

### 🎂 Age Calculator
Calculates the user's age based on their year of birth.

### 🐶 Dog Age Converter
Converts a dog's age into an approximate equivalent in human years.

### 💵 Currency Converter
Converts Brazilian reais into US dollars using a predefined exchange rate.

### 🌡️ Temperature Converter
Converts temperatures from Celsius to Fahrenheit.
